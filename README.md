# 资产库 AutoLibrary

**把音乐、影片与拍摄素材，整理成可浏览、可搜索、可播放的资料库。**

[发布与下载](../../releases) · [AutoPlay](https://github.com/hehedi/AutoPlay) · [AutoCard](https://github.com/hehedi/AutoCard) · [关联软件](#related-apps) · [授权条款](LICENSE)

免费使用 · 本机与远程资料库 · AutoPlay 播放联动 · 中文 / English

AutoLibrary 是一款基于 AutoPlay 播放能力的媒体资产库，用于整理音乐、影片、图片和拍摄素材。通过专辑、艺术家、影片详情、照片墙与目录视图浏览内容，结合封面、元数据、搜索和播放列表，让分散在文件夹中的媒体更容易找到和使用。

既可在一台电脑上管理本机资料库，也可创建并连接本地服务端，在不同电脑上浏览同一资料库并播放其中的媒体。可从 AutoPlay 主页进入，也可通过独立入口启动资产库客户端。

> **AutoLibrary 客户端需配合 AutoPlay 使用。** 安装客户端时会同时选择 AutoPlay 与资产库服务端；服务端也可单独安装。

## 核心功能

| 功能 | 说明 |
| --- | --- |
| **媒体收录与目录监听** | 按视频、音频和图片收录媒体，引用已有目录或从客户端传入文件；监听指定位置的新内容与变化，缺失来源可重新定位。 |
| **音乐专辑与艺术家** | 按标签组织专辑、曲目和艺术家，支持多碟专辑、CUE 分轨、专辑合并，以及已收录的 Booklet 浏览。 |
| **影片与剧集** | 通过封面和详情浏览影片，区分正片、剧集与附加内容；对可识别的来源提供集数、碟片和同片版本选择。 |
| **搜索与日常整理** | 全局搜索支持中文拼音、首字母、日语假名罗马音及明确别名；提供收藏、稍后再看、最近播放和自建播放列表。 |
| **资料与封面** | 查询并对照在线资料，按字段选择应用；管理封面、评分和已取得的人物信息，从艺术家或演职人员查看库内相关作品。 |
| **本机与远程访问** | 通过本机入口、局域网发现或手工地址连接资料库；服务端提供媒体数据，由客户端调用 AutoPlay 解码与播放。 |
| **跨终端播放控制** | 经授权后，将库内媒体交给另一台在线终端播放，控制播放、暂停、切换、进度和队列，并查看目标端的播放状态。 |
| **独立库文件与备份** | 使用 `.autolibrary` 文件保存目录索引、资料与缓存，支持手动备份、周期备份和恢复；原始媒体单独保存与备份。 |

## 音乐、影片与图片，各有合适的浏览方式

### 按专辑和艺术家整理音乐

- **目录与专辑两种视角**：按原有文件夹浏览，也可依据专辑和艺术家标签组织曲目；多碟专辑可选择碟片，并按碟号、曲号查看。
- **整理整张专辑**：预览曲目后合并专辑、调整碟曲顺序，保留曲目的文件位置与库内身份；已收录的 Booklet 可直接打开查看。
- **从作品找到创作者**：查看已保存的艺术家资料、参与人员与相关专辑，在明确的署名和资料关联之间浏览。
- **从浏览进入聆听**：选择整张专辑、部分曲目或从某首开始播放，沿用 AutoPlay 的封面、歌词、音频输出和分析功能。

### 让影片和剧集更容易找到

- **封面与资料一起看**：查看片名、简介、已保存的演职员资料，以及本地内容的时长、分辨率和色彩信息。
- **正片与附加内容分开**：对已识别的剧集、OVA、预告、菜单及其他附加内容分别展示，按集数或碟片选择播放。
- **管理同片不同版本**：将符合识别规则的不同编码版本、蓝光或 DVD 来源归入同一影片详情，选择需要的版本。
- **接着上次继续看**：从最近播放、稍后再看或影片详情返回内容，选择续播或重新观看。

### 浏览照片与拍摄素材

以目录、网格或列表查看媒体，照片墙保留图片原比例，并显示可读取的名称与拍摄时间。不同页面可分别记忆网格、列表和缩略图大小。

需要查看细节时，从资料库打开素材，使用 AutoPlay 已有的 RAW 回放、LUT 预览、HDR 显示、逐帧定位与音画分析。

## 找到内容，再整理成自己的收藏

全局搜索覆盖标题、专辑、艺术家，以及已经保存的影片简介和演职员资料。支持精确与模糊匹配，也可通过中文拼音、首字母或日语假名罗马音查找有对应索引的内容。

收藏、稍后再看、最近添加与最近播放分别提供入口。也可建立带自定义封面的命名播放列表，将独立视频和歌曲按自己的顺序编排；列表与封面随当前资料库保存，同库客户端可共同读取。

## 资料可手动整理，也可在线补充

通过在线元数据扩展查询专辑、影片、封面和人物资料，对照现有内容后选择要应用的字段。曲目可以单独核对与匹配，封面可以预览后决定是否替换。

已保存的资料随库保留，人物可关联库内作品；库内元数据、封面和星级也可手动编辑，并按当前保留的记录回退修改。

**自动资料匹配默认关闭。** 在当前库开启后，只处理之后新增的专辑与影片；存在标题、曲目、时长或候选歧义时，不自动套用资料。

在线资料与歌词查询需要网络及对应扩展，匹配结果以实际返回内容为准

## 本机使用，也能连接远程资料库

### 同一资料库，在不同电脑上使用

本机使用时，客户端按需启动本机服务端。需要多台电脑访问时，可在主机上运行服务端，由其他客户端通过局域网发现或指定地址连接。

服务端负责资料库、目录监听与媒体读取，播放端使用 AutoPlay 解码和输出。对支持的来源，客户端按需读取原始媒体数据，无需先复制整个资料库的媒体。

### 将播放交给另一台终端

在目标客户端允许接收控制、服务端授予相应权限后，可选择另一台在线终端播放当前库内的媒体。控制端显示目标的队列、进度、封面与歌词，实际声音和画面由播放端输出。

远程播放、主动下载、上传和播放控制分别受权限管理。外部网络访问需由服务端启用，并具备可连接的网络条件。

## 独立资料库与备份

- **一个库，一份独立数据**：`.autolibrary` 文件保存目录索引、封面、人物资料、播放列表及已生成缓存，方便备份、恢复和迁移。
- **手动或定期备份**：可立即备份，也可设置周期计划，并从保留的备份版本恢复资料库。
- **更换位置后继续使用**：媒体移动或服务器更换后，可重新定位来源，保持相应素材的库内身份、收藏与播放统计。

> **资料库备份不包含原始视频、音乐和图片。** 媒体原件需要单独备份；迁移资料库后，应让新的服务端能够访问原媒体。

## 更多管理与扩展能力

<details>
<summary>导入、目录监听与归档迁移</summary>

- 服务端可访问的已有目录可按引用方式收录；从另一台电脑传入的文件保存到服务端配置的接收位置。
- 每个监听位置可独立扫描、启停、编辑或移除；新文件、内容变化、来源缺失和恢复分别处理。
- 可调整监听或归档位置，按确认范围迁移媒体及关联文件，在复制与校验完成后更新库内引用。
- 任务面板显示扫描、预览和文件处理进度，提供失败原因、重试与重新定位入口。

</details>

<details>
<summary>访问密码、只读浏览与设备授权</summary>

- 为资料库设置访问密码；设密后可按需允许免密浏览与播放，未验证设备仅获得相应只读访问。
- 管理设备请求与授权，按操作批准、长期授权或撤销访问。
- 服务端保留连接、授权与文件变更日志，便于查看资料库的使用情况。
- 同一服务端可登记多个资料库，当前同时提供一个活动库；切换资料库会影响已连接客户端的当前库会话。

</details>

<details>
<summary>元数据、歌词与源文件标签</summary>

- 通过歌词扩展搜索、预览和调整时间偏移，并按可写位置保存外挂歌词。
- 对受支持的独立 FLAC 文件，可通过授权操作写回源标签；其他格式和组合素材的写回范围以当前版本为准。
- 库内资料更新与源文件写回是分别执行的操作，资料整理不等于所有格式的原文件都会被改写。

</details>

<details>
<summary>光盘浏览与远程媒体</summary>

- 浏览客户端本机已连接的 CD、DVD 与蓝光来源，读取可用资料
- 对受支持的远程单文件、已登记分段与蓝光内容按相应路线读取；部分来源需要先确认下载到本机再播放。

</details>

## 与 AutoPlay、AutoCard 配合使用

| 软件 | 主要职责 |
| --- | --- |
| **资产库 AutoLibrary** | 收录、整理、搜索和管理媒体，维护资料库、封面与播放列表，并连接播放终端。 |
| **[一键播放 AutoPlay](https://github.com/hehedi/AutoPlay)** | 提供媒体解码、影音播放与专业审阅能力，是 AutoLibrary 客户端的播放基础。 |
| **[一键导卡 AutoCard](https://github.com/hehedi/AutoCard)** | 负责从存储卡导入、校验、备份、转码与归档，归档后的媒体可继续交由 AutoLibrary 管理。 |

AutoLibrary 可读取 AutoCard 导卡 PDF 中的索引，辅助补全目录信息。AutoCard 的导卡校验、AutoLibrary 的资料整理和 AutoPlay 的播放审阅各自承担对应工作。

## 下载与安装

1. 在 [Releases](../../releases) 下载对应版本，查看客户端、服务端及平台支持说明。
2. 使用 Windows 安装包时，将同一发布批次的 `Setup.exe` 与匹配的 `Setup-1.bin` 放在同一目录后运行。
3. 在需要浏览和播放的电脑上选择 **AutoLibrary 客户端**，安装器会同时选择 AutoPlay 与资产库服务端；仅提供资料库服务的主机可单独安装服务端。
4. 启动 AutoLibrary，新建或打开本机库，也可通过局域网发现或服务器地址连接已有资料库。
5. 添加媒体目录或导入文件，先浏览已收录的内容，封面与预览会在后台继续生成；按需设置资料扩展、访问权限和备份计划。

**软件和功能组件均免费。** 专业解码、在线资料及其他扩展可按需安装。AutoLibrary 与 AutoPlay 共用播放设置和相关组件，具体平台、服务器镜像及功能以对应发行包为准。

## 使用范围说明

<details>
<summary>展开查看播放、资料与备份的适用范围</summary>

- 媒体的可播放格式、HDR、RAW 和音频输出能力取决于客户端 AutoPlay 及其组件，服务端不代替播放端完成解码。
- 远程访问的可用性与速度取决于网络、服务器可访问的媒体位置、权限和素材类型；跨终端控制用于操作选定的播放端。
- 库文件和备份不包含媒体原件，恢复资料库不会恢复已删除的原始媒体。
- 从库中移除记录与删除原件是不同操作；原件管理、迁移和回收的适用范围以当前版本及确认界面为准。

</details>
